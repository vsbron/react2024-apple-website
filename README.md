# Apple 15 Pro

A modern React SPA that replicates Apple's official iPhone 15 presentation page, showcasing a sleek, interactive product experience.

## Features

- **Header Navigation:** Simple, intuitive header navigation for quick access to different sections.
- **Hero Section:** A striking product presentation introducing the iPhone 15.
- **Highlights Section:** Video slider showcasing key product highlights and features.
- **Interactive Model Viewer:** Allows users to view the iPhone 15 in various models and colors.
- **Features Section:** Videos and animations highlighting the titanium build and premium materials.
- **Performance Section:** Details on the chip and capabilities that power the device.
- **Footer:** Contains essential information in a minimalistic layout.

## Details

- **Technology Stack:** Built with **React** and **TypeScript**.
- **Styling:** Handled with **Tailwind CSS** for efficient, responsive design.
- **Animations:** Managed through **GSAP** for smooth, engaging transitions.
- **3D Animations:** Created with **Three.js** for an immersive experience.
- **Custom Enhancements:** Extensive layout and animation improvements were added beyond the original design.
- **Responsive Design:** Optimized for mobile devices with a minimum width of 360px.
